# PR Diff Filter

Browser extension that hides tests, docs, lockfiles or any glob pattern you define from a GitHub pull request's changed files: the file tree, the diffs and the tab counter.

https://github.com/user-attachments/assets/4d7f7de6-6c46-4464-84c6-5d8110af8078

## Install

`chrome://extensions` → Developer mode → Load unpacked → select this folder.
