PR Diff Filter

Each filter is a list of glob patterns, one per line. A pattern without / matches the file name anywhere (*.md); a pattern with / matches from the repository root (docs/**, **/test/**). * matches within one folder, ** across folders. A leading / anchors a file name to the root (/README.md), and a trailing / means everything inside (docs/ is docs/**). Braces like {js,ts} are not supported. Turn filters on and off from the panel on a pull request.
